# MemeLab — Rat Universe

Two separate meme coins sharing the same MemeLab universe.

## 1. Rocket Rat

- Name: Rocket Rat
- Ticker: RKTROT
- Role: Flagship / hero coin
- Personality: Confident, optimistic, moon-bound
- Visual identity: Grey rat, astronaut helmet, red rocket, gold/orange/red
- Core mascot: Viral Meme Mascot concept #1

## 2. Degen Rat

- Name: Degen Rat
- Ticker: DGRAT
- Role: Degen / chaos sister coin
- Personality: Wild, reckless, funny, high-energy
- Visual identity: Same rat universe, pink/purple/black, X-lens glasses, gold chain, cash
- Core mascot: Degenerate Rat concept #3

## Shared DNA

Both coins:
- Same rat universe
- Same overall mascot language
- Same MemeLab origin
- Different personalities
- Different visual colour systems
- Completely separate tokens

The two coins must never share a mint address.

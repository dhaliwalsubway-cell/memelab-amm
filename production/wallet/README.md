# MemeLab Production Wallet

This directory contains documentation only.

The production Solana signer must be maintained separately from the local development wallet.

Requirements:
- dedicated production keypair
- never commit private key material
- never paste seed phrases into chat
- never store private key material in Git
- production signer must be explicitly selected before mainnet execution
- `memelab-devnet.json` is permanently rejected by the production wallet gate

No production transaction is created by this documentation.
